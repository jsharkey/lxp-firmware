# Whole-surface parity scoreboard (T23)

Generated by the whole-surface read sweep ([`tests/test_regsweep.py`](../../../tests/test_regsweep.py)
/ [`regsweep_contract.py`](../../../tests/regsweep_contract.py)): both images are
booted into the **same seeded state** (a fixed battery CAN snapshot + default RTC),
then **every** dongle register — IR 0-159, IR 5000-5126, HR 0-255 — is read in
spec-legal chunks (≤40, no 40-group crossing) and ours is diffed against the factory,
value-or-exception per register. The committed classification lives in
[`regsweep_expected.py`](../../../tests/regsweep_expected.py) (the test fails if the
live diff drifts from it). Run `make regsweep` to reproduce; add `--dump` to print
every diff.

**Image:** `ceaa-07xx_vE_260214` (the 07-series). **Seed:** CAN `0x355/0x356/0x359`
(SOC 77 / SOH 96, V 53.25 / I 1.5A / T 23.1, chg-V 56.0, fault 0x0102 / warn 0x0408,
3 modules); HR settings are **not** seeded — see the note at the bottom.

## Framing (the one deliberate asymmetry)

Four out-of-contract reads, on both images:

| read | ours | factory (USART3 slave) |
|---|---|---|
| crosses a 40-group boundary | **exception 2** | served |
| longer than 40 registers | **exception 2** | served (41 values) |
| zero-length | **exception 2** | served (empty) |
| out-of-map address | **exception 2** | served (`0`) |

Our firmware enforces the documented dongle query rule (≤40, no 40-group crossing,
in-map → else exception 2). The factory's **USART3 fallback slave** — the port the
harness can reach — is lenient. That is **not** ours being wrong: the rule belongs to
the factory's real **UART5 dongle handler** (`sub_0802afe2`), which is an RTOS
scheduler task the bare harness can't run (T02); the USART3 slave is a different,
permissive handler we use only as a register oracle. So this row is recorded, not
asserted equal.

## Note — why HR settings are not seeded here

Writing the HR settings table over the wire (as T03's `SETTINGS_MAP` does) **silences
the factory's USART3 slave**: a mode/enable write (SysEnable / SysType / FuncEn, and
ComAddr which also moves the slave address) takes it out of the state where it answers
EG4-Modbus on USART3. So this sweep uses the **cold** HR state, which is why 91 HR
registers show the "no default" gap. Per-register settings **parity** is proven
elsewhere — the write path by T04 and cross-image persistence by T03. Re-seeding every
HR and re-sweeping both (so those 91 collapse to `match`) is the **T23b** follow-up,
blocked on keeping the factory USART3 slave alive under settings writes.

## How to use this scoreboard

It is the parity ledger: new work should turn **ours-red** into **match** (implement
per-pack → the 127 shrink; wire the 8 unpopulated IRs → they match). Each such change
regenerates `regsweep_expected.py` (review every delta) and this table. The
`known-diff` rows are intentional and cite their task/quirk.
