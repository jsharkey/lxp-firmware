# Progress archive — the bootstrapping milestone log

This is the historical, append-only log of reverse-engineering and implementation
milestones from the project's bootstrapping phase. It used to live in the
top-level `README.md`.

**For *active* work, this is superseded by the parity task board
[`docs/39-parity-roadmap.md`](39-parity-roadmap.md)** — claim and track specific
tasks there. This page is kept only as the record of how we got here (every item
links to the doc that established it). ✅ done · 🚧 in-progress · ⬜ open.

- [x] ✅ **ARM↔DSP USART3 RX demystified (T09)** → the ARM does **not** parse a DSP `0x49` telemetry frame on USART3. The USART3 RX is a **Modbus-slave (`03/04/06/10`) + DSP-bootloader (`21/22/23`) demux**; a `0x49`/type-1 frame is rejected. The `0x49` parse is the **USART2** safety-CPU path — so "live telemetry from the DSP" reaches the ARM via **USART2** (docs/33), not USART3. Reimplemented in `src/dsp/dsp_rx.c` + `dsp_rx_port.c`; quirk [`docs/31`](31-factory-quirks.md) Q10
